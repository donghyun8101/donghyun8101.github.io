# 👑 동현님 비서실

이동현님 전용 비서실 웹앱입니다. 모바일·PC 겸용 정적 웹앱(단일 `index.html`)이며, 서버 없이 동작합니다.

- 주소: https://donghyun8101.github.io/secretary/
- 구성: 회의실(대회의실·지휘실·라운지) · 작업실 · 비서현황 · 메모
- 연결: 데모 모드 / Google Gemini API / Anthropic Claude API / 집 노트북(OpenAI 호환) 서버 — ⚙️ 설정에서 전체 또는 비서별로 선택
- 저장: 대화·작업·메모·설정은 브라우저 localStorage에만 저장 (내보내기/불러오기 제공)

## 🕺 미니 오피스 (졸라맨 스테이지)

회의실·작업실 상단에 비서들이 책상에 앉아 있는 미니 오피스가 있습니다. 접기/펼치기가 됩니다.

- **2줄 배치**: 모바일(390px)에서도 크게 보이도록 윗줄 4명 / 아랫줄 3명(flex-wrap 가운데 정렬, 칸당 약 85~90px)으로 배치합니다. 비서가 늘면 자동으로 다음 줄로 넘어갑니다.
- **발밑 토큰 게이지**: 각 졸라맨 이름 밑에 초소형 막대와 `99% · 998k`(남은 비율 · 남은 토큰)가 항상 표시됩니다. 30% 이하면 주황, 10% 이하면 빨강.

## 🪙 토큰 사용량

- 비서별로 `오늘/이번 달/누적 사용량 · 요청 횟수 · 일일 한도`를 관리하고 localStorage에 저장합니다.
- 실제 연결 시 응답의 usage를 그대로 집계합니다 — Gemini `usageMetadata`, Claude `usage(input_tokens/output_tokens)`, OpenAI 호환 서버 `usage.total_tokens`.
- 데모 모드에서는 프롬프트·지시·응답의 글자 수로 추정한 토큰을 쌓아 게이지가 움직입니다. 데모에서 시작한 예시 사용량은 **첫 실제 호출 때 0으로 리셋**됩니다.
- 한도는 `⚙️ 설정 → 토큰 한도`(기본 일일/월간)와 `📊 비서현황` 카드의 **한도 수정**(비서별, 0 = 무제한)에서 바꿉니다.
- 표시되는 '남은 토큰'은 목표 예산 기준이며, Google·Anthropic 계정의 실제 잔여 크레딧을 조회하는 값은 아닙니다(브라우저에서 조회 불가).

- 기본 비서 7명: 🌸 하나 · 🛡️ 심사비서 · ✍️ 콘텐츠비서 · 🦉 헤르메스 · 📎 어사이드 · ✨ 제미나이 · 🧠 클로드
  (v1 저장본은 처음 열 때 제미나이·클로드가 자동으로 추가됩니다)
- 상태 연동: 대기(숨쉬기·고개 까딱·커피김) / 작업 중(`@멘션` 응답 생성 중, 또는 작업실 '진행 중' 1건 이상 → 타자 치기 + `⚡ 작업중…`) / 완료(점프·만세 + `✅ 보고완료!`)
- 졸라맨을 누르면 귀여운 한마디 말풍선이 뜹니다.
- 비서현황에서 새 비서를 추가하면 기본 졸라맨 캐릭터가 자동 배정됩니다(색·소품 순환).
