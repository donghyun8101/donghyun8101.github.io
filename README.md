# 실손 심사 도우미 (silson-helper)

삼성생명 인보험 심사 실무용 **모바일 웹앱**입니다. 아이폰 사파리에서 열어 ‘홈 화면에 추가’하면 앱처럼 전체 화면으로 뜨고, 책상 옆에서 바로 씁니다.

- 기준일: **2026-11-23**
- 구조: 서버·DB 없는 순수 HTML + CSS + Vanilla JS (정적 호스팅 가능, 오프라인 동작)
- 심사메모: 기기 브라우저(localStorage)에만 저장 — 외부 전송 없음

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS 단일 파일) |
| `manifest.json` | PWA 매니페스트 (이름·아이콘·테마) |
| `sw.js` | 오프라인 캐시 서비스 워커 (network-first) |
| `icon-180.png` / `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | 홈 화면 아이콘 |

## 아이폰에 설치

1. Safari로 배포 주소(`https://…/silson-helper/`)를 엽니다.
2. 하단 **공유** → **홈 화면에 추가**.
3. 홈 화면의 **실손도우미** 아이콘으로 실행하면 주소창 없이 열립니다.
4. 한 번 열어 두면 이후 인터넷이 없어도 실행됩니다(서비스 워커 캐시).

> `file://`로 직접 열면 화면은 동작하지만 서비스 워커·홈 화면 추가는 되지 않습니다. `https` 또는 `localhost`로 여세요.

| 2세대 | 표준형 80% / 선택형Ⅱ 90%, 5천만 | 정액 공제(의원 1만·병원 1.5만·상급/종합 2만) 또는 MAX(정액, 20%), 회당 30만 | 80% | 구분 없음(일반 비급여) |

| 4세대 | 80% + 자기부담 연 200만 초과분 | MAX(1만·2만, 20%), 회당 20만 | 70% | 공제 MAX(3만, 30%), 연 350만/250만/300만 |

| 5세대 비중증 | 80% + 초과분, 5천만 | 위와 동일 | 50%, 입·통원 연 1천만 | 도수·주사 면책 / MRI 공제 MAX(5만, 50%), 연 200만 |

### 한도·횟수 반영 방식

- **연간 한도**: 세대·구분별 약관 한도를 기본값으로 두고, 사용자가 **한도**와 **기사용(누적)**을 직접 수정할 수 있습니다(1세대 비표준화·가입금액별 상품 대응). 이번 지급액이 `한도 − 기사용`을 넘으면 넘는 만큼 비례 차감하고, 결과 카드에 `한도 초과 차감: -OOO원 (잔여 한도 OOO원)`으로 표시합니다.
  - 1세대: 입원 3천만(질병·상해 합산) · 통원 연 30회
  - 2·3세대: 입원 5천만 · 통원 연 180회
  - 4세대: 급여 5천만 · 비급여 5천만 · 비급여 통원 연 100회
  - 5세대 중증: 급여 5천만 · 중증 비급여 5천만 · 중증 통원 연 100회 / 비중증: 급여 5천만 · 비중증 1천만 · 통원 연 100일
  - 3대 비급여(350만/250만/300만, 5세대 비중증 MRI 200만)와 상급병실료 차액은 위 연간 한도와 **별도**로 계산합니다.
- **3대 비급여 횟수**: 올해 기사용 횟수 + 이번 청구 횟수를 넣으면 50회 잔여만 인정하고 초과 회차는 면책합니다(회당 공제 × 인정 회차). 4세대·5세대 중증은 최초 10회 후 10회 단위로, **11·21·31·41회차 도래 시 경고 배지**를 표시합니다.
- **5세대 중증 입원 500만 상한**: 상급종합·종합병원 입원의 중증 비급여 **공제(자기부담)**를 연 500만원까지만 차감합니다(근골격계 이학요법·체외충격파·주사료 제외, MRI 포함). 기사용 공제 누계를 입력하면 초과분을 전액 보상합니다.
- **상급병실료 차액**: `MIN(차액 × 50%, 이용일수 × 10만원)`.

다수계약: `비중 = 독립책임액 ÷ Σ독립책임액`, `지급액 = MIN(손해액 × 비중, 독립책임액)`. 독립책임액 자동 산출은 단일계산의 한도·횟수 설정을 그대로 적용합니다.

## 주의 (앱에도 표시됨)

1. **1세대는 비표준화 세대**입니다. 계산값은 생보협회 공시 대표상품(입원 20%·통원 5천원+20%, 입원 연 3천만) 기준이므로 증권·가입 당시 약관의 보상률·한도를 한도 칸에서 직접 수정해 확인해야 합니다.
2. **한도·기사용은 사용자가 넣는 값**입니다. 앱은 그 값으로 잔여 한도를 계산할 뿐, 청구 이력과 대조하지 않습니다. 3대 비급여·연간 한도는 계약(증권) 단위로 확인하세요.
3. 통원은 **회차별** 계산입니다(회차별 한도 각각 적용). 3대 비급여는 **특약 가입 전제**입니다.
4. 5세대 중증 500만 상한은 상급종합·종합병원 **입원** 건에만 적용되고, 3대 중 근골격계 이학요법·체외충격파·주사료는 상한 계산에서 제외됩니다.
5. 계산 결과는 약관 기준을 옮긴 참고값이며, 실제 지급 결정은 증권·약관 원문과 진료기록으로 판단합니다.
