# 실손 심사 도우미 (silson-helper)

삼성생명 인보험 심사 실무용 **모바일 웹앱**입니다. 아이폰 사파리에서 열어 ‘홈 화면에 추가’하면 앱처럼 전체 화면으로 뜨고, 책상 옆에서 바로 씁니다.

- 기준일: **2026-11-23**
- 구조: 서버·DB 없는 순수 HTML + CSS + Vanilla JS (정적 호스팅 가능, 오프라인 동작)
- 심사메모: 기기 브라우저(localStorage)에만 저장 — 외부 전송 없음

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML + CSS + JS 단일 파일) |
| `manifest.json` | PWA 매니페스트 (이름·아이콘·테마) |
| `sw.js` | 오프라인 캐시 서비스 워커 (network-first) |
| `icon-180.png` / `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | 홈 화면 아이콘 |

## 아이폰에 설치

1. Safari로 배포 주소(`https://…/silson-helper/`)를 엽니다.
2. 하단 **공유** → **홈 화면에 추가**.
3. 홈 화면의 **실손도우미** 아이콘으로 실행하면 주소창 없이 열립니다.
4. 한 번 열어 두면 이후 인터넷이 없어도 실행됩니다(서비스 워커 캐시).

> `file://`로 직접 열면 화면은 동작하지만 서비스 워커·홈 화면 추가는 되지 않습니다. `https` 또는 `localhost`로 여세요.

## 배포 (GitHub Pages 예시)

```bash
# 1) 저장소를 만들고 이 폴더의 파일을 그대로 올립니다 (하위 폴더 silson-helper/ 로 올려도 됨)
git init && git add . && git commit -m "실손 심사 도우미"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main

# 2) GitHub → Settings → Pages → Source: Deploy from a branch / main / (root) 선택
# 3) 잠시 후 https://<계정>.github.io/<저장소>/index.html 접속
```

사내망·개인 서버의 정적 디렉터리에 넣어도 됩니다(nginx, S3, Netlify 등). 빌드 과정은 없습니다.

## 계산식 (앱에 구현된 기준)

| 세대 | 급여 입원 | 급여 통원 | 비급여 | 3대 비급여 |
|---|---|---|---|---|
| 1세대 | 80%, 연 3천만 | 공제 5천원+20%, 회당 10만 | 급여와 합산 80% | 구분 없음(일반 비급여) |
| 2세대 | 표준형 80% / 선택형Ⅱ 90%, 5천만 | 정액 공제(의원 1만·병원 1.5만·상급/종합 2만) 또는 MAX(정액, 20%), 회당 30만 | 80% | 구분 없음(일반 비급여) |
| 3세대 | 표준형 80% / 선택형Ⅱ 90%, 5천만 | 정액 공제, 회당 30만 | 80% | 공제 MAX(2만, 30%), 연 350만/250만/300만 |
| 4세대 | 80% + 자기부담 연 200만 초과분 | MAX(1만·2만, 20%), 회당 20만 | 70% | 공제 MAX(3만, 30%), 연 350만/250만/300만 |
| 5세대 중증 | 80% + 초과분, 5천만 | MAX(1만·2만, 20%, 건보 본인부담률), 회당 20만 | 70% | 공제 MAX(3만, 30%), 연 350만/250만/300만 |
| 5세대 비중증 | 80% + 초과분, 5천만 | 위와 동일 | 50%, 입·통원 연 1천만 | 도수·주사 면책 / MRI 공제 MAX(5만, 50%), 연 200만 |

다수계약: `비중 = 독립책임액 ÷ Σ독립책임액`, `지급액 = MIN(손해액 × 비중, 독립책임액)`.

## 주의 (앱에도 표시됨)

1. **1세대는 비표준화 세대**입니다. 계산값은 생보협회 공시 대표상품 기준이므로 증권·가입 당시 약관의 보상률을 확인해야 합니다.
2. 5세대 **중증 특약의 상급종합·종합병원 입원 자기부담 연 500만원 상한**은 계산기에 반영하지 않았습니다. 고액 입원 건은 별도 확인.
3. 통원은 **회차별** 계산입니다(회차별 한도 각각 적용). 3대 비급여는 **특약 가입 전제**입니다.
4. 계산 결과는 약관 기준을 옮긴 참고값이며, 실제 지급 결정은 증권·약관 원문과 진료기록으로 판단합니다.
